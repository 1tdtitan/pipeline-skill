# Starter guide for MSPs with fewer than 20 clients

*Fictional document for the pipeline skill demo.*

A short guide for smaller managed service providers.

## Start with your three riskiest clients

Pick the clients where a failed restore would hurt most, and protect those first.

## Make daily checks a five-minute job

Use a single dashboard view sorted by clients that need attention, so a technician does not have to open each client in turn.

## Set a restore test schedule

Test one restore per client per quarter and keep a record. Insurers and auditors increasingly ask for one.
