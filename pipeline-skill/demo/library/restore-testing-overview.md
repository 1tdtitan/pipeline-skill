# Restore testing overview

*Fictional document for the pipeline skill demo.*

How Pellmoor verifies that a backup can be restored.

## What it does

- Boots each protected device from its latest backup on a schedule and records the result
- Flags any device whose test fails
- Produces a quarterly restore test report for each client

## Who it is for

Partners who need to show clients, insurers, or auditors that restores are tested.

## Requirements

The device must be protected by Pellmoor for at least one full backup cycle.
